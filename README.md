# Kita Wrapped

Rangkuman tahunan pasangan ala "Wrapped": total chat, jumlah "udah makan belum?", tempat makan terfavorit, lagu yang paling sering didengerin, dan lain-lain.

Versi ini masih **contoh dengan data karangan**. Semua isi slide ada di array `slides` di `index.html`. Ganti angka, teks, dan warna di sana.

## Navigasi
- Klik kartu untuk lanjut, klik sisi kiri untuk mundur
- Tombol panah keyboard juga bisa

## Bahan data untuk versi asli
- Ekspor chat WhatsApp (Ekspor chat → Tanpa media) untuk jumlah pesan, kata favorit, jam aktif
- Daftar lagu, tempat makan, dan momen favorit
